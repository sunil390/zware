# Spec driven development.

## Setup in Ubuntu

1. sudo apt install python3
2. curl -LsSf https://astral.sh/uv/install.sh | sh
3. uv venv
4. source .venv/bin/activate
5. uv init znext
6. uv add tnz ebcdic
7. git config --global user.name "Sunil Sukumaran"
8. git config --global user.email "Sunil390@gmail.com"
9. curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
10. nvm install --lts
11. npm install -g @fission-ai/openspec@latest
12. openspec init
13. openspec config profile
